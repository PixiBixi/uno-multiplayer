# Bots Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bot seats at Easy, Normal and Hard (God Level gated on measurement), solo tables, and a bot standing in for a disconnected or departed human, with human-paced timing.

**Architecture:** The decision functions are pure and live in `packages/engine/src/bot/`, deciding from a `BotView` that structurally cannot hold hidden cards. `Room` stays synchronous and timer-free: it gains a bot-aware member model and `botStep` / `botReact` entry points. `RoomManager` owns every bot delay behind the existing injectable `Timers`. The client renders bot seats and the host's lobby controls; it still knows no rules.

**Tech Stack:** TypeScript, Vitest, fast-check, Fastify + Socket.IO, Zod, React, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-01-bots-design.md`

## Global Constraints

- `packages/engine` stays pure: no I/O, no `Math.random`, no `Date`. All randomness through `nextRandom` / `nextInt` from `packages/engine/src/rng.ts`.
- Dependency direction: engine -> protocol -> server -> web. `BotLevel` is declared in the engine and re-exported by the protocol.
- A bot decides from `BotView` only. `BotView` never contains another seat's hand or the draw pile's contents or order.
- Every move a bot returns is one of the `legalMoves` it was given.
- Four seats maximum (`MAX_SEATS = 4`). A table deals with at least one human and at least two filled seats.
- Own-turn delay: Gaussian clamped to 800-3000 ms, means Easy 2200, Normal 1800, Hard 1400, God 1400, sd 500.
- Off-turn call-out and late UNO: Gaussian clamped to 2000-10000 ms, means Easy 7000, Normal 5000, Hard 3000, God 3000, sd 1500.
- Off-turn jump-in: Hard and God only, Gaussian clamped to 1000-3000 ms, mean 1800, sd 500. Easy and Normal never jump in.
- On a Blazing table, a bot's own-turn delay is capped at `turnSeconds * 1000 - 1000`.
- Absent-turn grace: `min(15000, turnSeconds * 1000 - 1000)` ms, first absent turn only.
- A stand-in plays at `'normal'`.
- No bot moves while no human is connected.
- Level labels: en `Easy` / `Normal` / `Hard` / `God Level`; fr `Facile` / `Normal` / `Difficile` / `God Level`.
- A user-facing string needs `messages.ts`, `en.ts` and `fr.ts` (AGENTS.md).
- `npm run verify` before every commit, exit code checked. Conventional Commits, one scope per commit, `git commit -F <file>`.

## Review Focus

1. **Every human disconnects while a bot is on turn.** Expect nothing to move until a human reconnects, and no timer re-arming in a loop. Test in Task 8.
2. **A human reconnects while their stand-in's own-turn timer is pending.** Expect the pending bot move to be cancelled and the human to play their own turn. Test in Task 8.
3. **A bot reaction fires after its window has closed** (call-out target already called UNO, jump-in card no longer on top). Expect no move, no error, no event. Test in Task 7.
4. **The host removes a bot, then a human joins, then the host starts.** Expect seat numbers to still equal engine indices and no "left" ghost in the roster. Test in Task 6.
5. **All humans press Leave mid-match.** Expect the room to be `abandoned` and purged, not a table of bots playing forever. Test in Task 7.

  ```ts
  /** The seat's own turn. Never null when legalMoves holds an on-turn move. */
  export function botMove(view: BotView, level: BotLevel, rng: number): { move: Move | null; rng: number }
  export type ReactionKind = 'callOut' | 'lateUno' | 'jumpIn'
  /** Which off-turn reactions are legal for this seat right now. */
  export function availableReactions(view: BotView): ReactionKind[]
  /** An off-turn move of that kind, or null to let the moment pass. */
  export function botReaction(view: BotView, level: BotLevel, kind: ReactionKind, rng: number): { move: Move | null; rng: number }
  ```

  Behaviour:
  - Easy, own turn: `callUno` with probability 0.5 when legal, otherwise uniform over the other legal moves.
  - Normal, own turn: `callUno` whenever legal; else play the legal coloured card with the highest `cardPoints`, ties broken by keeping the colour it holds most of; a wild only when no coloured card is legal; wild colour = colour most held (ties: first in `COLORS`); a 7's `swapWith` = smallest opponent hand; `+2`, skip and reverse preferred when the next seat in `turnOrder` holds the fewest cards; never `draw` while a play is legal; in the drawn-card sub-state, play the drawn card unless it is a wild and the hand holds another card of the current colour, then `pass`.
  - `callOut`: Easy returns it with probability 0.5, Normal always. `lateUno`: always taken when offered. `jumpIn`: Easy and Normal always null.
